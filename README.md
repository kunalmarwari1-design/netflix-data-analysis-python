# Netflix Data Analysis using Python

A beginner-friendly data analytics project exploring Netflix Movies and TV Shows using Python, Pandas, NumPy, and Matplotlib.

## 📌 About the Project

This project analyzes the Netflix Movies and TV Shows dataset to identify patterns and trends in Netflix content.

The project includes data cleaning, data exploration, analysis, and visualization.

## 🎯 Objective

The main objective of this project is to explore the Netflix content library and analyze:

- Content types
- Release year trends
- Countries
- Content ratings
- Genres
- Movie durations
- Directors

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## 🧹 Data Cleaning

The dataset was prepared before analysis by:

- Checking the dataset structure
- Checking duplicate records
- Checking missing values
- Handling missing values
- Preparing columns for analysis

## 📊 Analysis Performed

The project contains 8 main analyses:

1. Movies vs TV Shows
2. Content Released by Year
3. Top 10 Countries
4. Most Common Content Ratings
5. Top 10 Genres
6. Movies vs TV Shows Over the Years
7. Movie Duration Distribution
8. Top 10 Directors

## 📈 Visualizations

Matplotlib was used to create different visualizations including:

- Bar charts
- Pie charts
- Line charts
- Horizontal bar charts
- Histograms
